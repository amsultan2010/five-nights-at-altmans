# Photos

Transparent cut-outs, cropped to the person. File names follow the original
character each person replaces:

| Prefix | Cast member |
|---|---|
| `freddy_*`, `fred*` | Altman |
| `bonnie_*` | The Zuck |
| `chica*` | Dario |
| `foxy_*` | Elon |
| `golden*` | Jensen |

`*_title` photos are the faces on the title screen and `*_flick` photos are the
title flickers. `openai_logo.png` goes on the newspaper ad.
